# Walk one paper scenario

## Inputs

- Working: selected G-1 or T-1 question and permitted candidate/evidence, if any.
- Reference: [governance-change.md](governance-change.md) for declarative governance, or [tooling-change.md](tooling-change.md) for technical reference checks.
- Read the selected fixture's governing-rule links only as needed for its affected transition; select corresponding Role entries/Profile rows in [coverage](../framework/role-coverage.md#canonical-role-inventory).
- Read [paper scope and exclusions](../framework/baseline.md#selected-paper-fixtures-and-exclusions) and [recording observations](governance-change.md#recording-observations) or [tooling observations](tooling-change.md#recording-observations) for the chosen fixture.

## Process

1. Follow the selected fixture's inputs, scenario data, expected transitions and applicability.
2. Trace the assigned normal/correction/conflict path without inventing approvals, execution or outcomes.
3. Record observations separately from expectations. Change fixture meaning only when that change is assigned.

## Outputs

A scoped walkthrough/evidence record at its assigned location, or an authorized fixture diff. Neither fixture implements its hypothetical candidate.

## Human check

At the existing [PR check](../CONTEXT.md#human-check), verify preserved scenario scope and the expected-versus-observed distinction.
