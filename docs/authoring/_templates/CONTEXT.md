# Copy a definition template

## Inputs

Select [role.md](role.md) for a Role or [profile.md](profile.md) for a Profile. Use the assignment and relevant inputs in the [authoring contract](../CONTEXT.md).

## Process

Copy the selected file to the assigned draft path. Replace placeholders using the [format guidance](../definition-format.md#completeness-and-gaps). Preserve required fields; edit the template itself only when the shared format is the assigned change.

## Outputs

A copy at the assigned destination. These two template payloads are the canonical reusable starting text.

## Human check

At the existing [PR check](../../CONTEXT.md#human-check), verify the copy has substantive field content or justified dispositions.
